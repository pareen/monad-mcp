Claude Code recommended

One command in your terminal. Two ways — the hosted URL (nothing to install) or run the package locally with npx.

A · Hosted URL — read-only, zero install
claude mcp add --transport http monad https://monad-mcp.fly.dev/mcp
B · Run locally with npx — read-only, no keys
claude mcp add monad -- npx -y monad-mcp
Restart Claude Code, then ask: “What's the balance of 0x7E274bCA90eEfa81761080e074AFb1D354a0c552 on Monad testnet?” Remove any time with claude mcp remove monad.

Claude Desktop

Claude Desktop speaks stdio, so the hosted URL goes through the mcp-remote shim. Open your config and add the monad entry.

1 · Open the config file
# macOS
open ~/Library/Application\ Support/Claude/claude_desktop_config.json
# Linux:   ~/.config/Claude/claude_desktop_config.json
# Windows: %APPDATA%/Claude/claude_desktop_config.json
2 · Add the monad server (hosted, read-only)
{
  "mcpServers": {
    "monad": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://monad-mcp.fly.dev/mcp"]
    }
  }
}
Prefer running the package directly? Swap the args for ["-y", "monad-mcp"] and add "env": { "MONAD_DEFAULT_NETWORK": "testnet" }. Then quit Claude Desktop completely (⌘Q — closing the window isn't enough) and reopen.

ChatGPT custom connector

ChatGPT connects to remote MCP servers over streamable HTTP. Add monad-mcp as a custom connector and paste the hosted URL.

Steps

Open connector settings

In ChatGPT, go to Settings → Connectors (you'll need a plan with custom connectors / developer mode enabled), then Create a new connector.

Paste the MCP server URL

https://monad-mcp.fly.dev/mcp

Name it monad. No authentication is required — the hosted endpoint is read-only.

Use it in a chat

Enable the connector for your conversation and ask for a Monad balance, token price, or portfolio. ChatGPT will call the read tools directly.

Read-only. Custom connectors are great for reads. Transfers and swaps need a signer the hosted URL doesn't carry — run your own server for writes (developer guide).

claude.ai custom connector

The web/app version of Claude connects to remote MCP servers the same way — add a custom connector and paste the URL.

Steps

Open Connectors

Go to Settings → Connectors → Add custom connector (available on plans that support custom connectors).

Paste the MCP server URL

https://monad-mcp.fly.dev/mcp

Give it the name monad and save. No auth needed.

Ask away

Toggle the connector on and ask for balances, prices, token info, or a portfolio.

Verify the endpoint is alive: curl https://monad-mcp.fly.dev/health → {"ok":true,…,"privy_enabled":false}. The hosted machine sleeps after ~5 min idle, so the first call may cold-start.

Why monad-mcp

Built for agents, not humans clicking buttons

A person will approve every transaction. An agent running a strategy at 2am won't. The hard part isn't wrapping an RPC — it's letting an agent act autonomously inside a boundary you trust.

🔑

Keys never touch the server

Privy holds the private key in a TEE. The MCP server builds unsigned transactions and hands them off — it can never move funds on its own.

✋

Approval by default

Write actions return a one-time approval link with a simulated asset diff. You review and confirm; the agent polls for the tx hash.

⚡

Session keys for autonomy

Authorize a scoped budget once — spend cap, expiry, recipient + function allowlists — and the agent transacts within it, no per-tx clicks.

🛡️

Defense in depth

Each grant is mirrored as a Privy wallet policy, so Privy itself refuses transactions outside the envelope — even if the server is compromised.

The write flow

How it works

From “send 1 MON” to a confirmed transaction — without the agent ever holding a key.

You ask in chat

“Stake 1 MON with FastLane, then send 0.1 MON to alice.mon.”

The agent builds an unsigned transaction

The MCP server encodes the call with viem, simulates the asset changes, and stores it — returning an approval URL carrying a one-time capability token.

You approve (once)

Open the link, see exactly what moves, confirm. Privy signs with your embedded wallet. Or grant a session key once and skip this for everything inside the budget.

The agent reports back

It polls the request, gets the transaction hash, and shows you the explorer link. Done.

For developers

Run your own server

The hosted URL is read-only on purpose. To let your agent sign and send — transfers, swaps, staking, session keys — run monad-mcp yourself with a Privy app. It's the dogfood path.
